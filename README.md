# ЛР 1. Шифри заміни та перестановки

Навчальна програма, що шифрує і розшифровує український текст чотирма класичними алгоритмами:

| Алгоритм | `-a` | Ключ |
|---|---|---|
| Проста підстановка | `substitution` | ключове слово або повна таблиця з 33 літер |
| Шифр Віженера (mod 33) | `vigenere` | слово з українських літер |
| Блокова перестановка | `block` | перестановка, напр. `"3 2 5 1 4"` |
| Вертикальна перестановка | `columnar` | порядок стовпців, напр. `"3 1 4 2"` |

> Класичні шифри не захищають дані. Для реальних систем використовують AES-GCM через перевірені бібліотеки.

## Вимоги

* Python 3.10+ (перевірено на 3.13)
* зовнішні залежності лише для тестів: `pytest`, `hypothesis` (необов'язково)

```bash
python -m venv venv
venv\Scripts\activate          # Windows  (Linux/macOS: source venv/bin/activate)
pip install -r requirements.txt
```

## Запуск

```bash
python cli.py --help
python cli.py rules                                            # правила підготовки тексту
python cli.py encrypt -a vigenere -k КЛЮЧ -t "Слава Україні"   # ВЬЮЩК ДЇККЧЛД
python cli.py decrypt -a vigenere -k КЛЮЧ -t "ВЬЮЩК ДЇККЧЛД"
python cli.py encrypt -a substitution -k ЯЮЬЩШЧЦХФУТСРПОНМЛКЙЇІИЗЖЄЕДҐГВБА -t "Слава Україні"
python cli.py encrypt -a block -k "3 2 5 1 4" -m letters -t "Слава Україні"
python cli.py encrypt -a columnar -k "3 1 4 2" -t "Криптографія"
python cli.py decrypt -a columnar -k "3 1 4 2" --pad 0 -t "ИГІКТАПРЯРОФ"
python cli.py encrypt -a vigenere -k КЛЮЧ -i plain.txt -o cipher.txt   # файли UTF-8
python cli.py encrypt -a vigenere -k КЛЮЧ                              # ручне введення
```

При помилці програма друкує `Помилка: ...` і завершується з кодом 1.

## Специфікація обробки тексту

* UTF-8, нормалізація Unicode NFC, верхній регістр.
* Алфавіт: `АБВГҐДЕЄЖЗИІЇЙКЛМНОПРСТУФХЦЧШЩЬЮЯ` (33 літери).
* Пробіли, цифри, розділові знаки, переноси рядків зберігаються; у Віженері не просувають ключ.
* Літери інших алфавітів (латиниця, Ы, Э, Ё) — помилка.
* Перестановки: режим `preserve` (за замовчуванням) переставляє весь текст; `letters` спершу лишає тільки літери (незворотний щодо пробілів).
* Блокова перестановка: неповний останній блок не змінюється.
* Вертикальна перестановка: доповнення символом `_`, кількість доповнення виводиться окремо (`Доповнення: N`) і передається через `--pad N`.

## Тести

```bash
python -m pytest -v
```

| Файл | Що перевіряє |
|---|---|
| `test_vectors.py` | 4 обов'язкові контрольні вектори (пряме і зворотне перетворення) |
| `test_roundtrip.py` | D(E(x)) = x для 12 повідомлень × кількох ключів |
| `test_edges.py` | NFC, Ґ Є І Ї, порожній текст, 1 символ, довжина блоку ±1, доповнення |
| `test_invalid_keys.py` | порожні/повторювані/поза діапазоном ключі, сторонні літери |
| `test_files.py` | UTF-8 файли, кілька рядків, завершальний перенос, атомарний запис |
| `test_properties.py` | генеративні тести (Hypothesis), пропускаються без бібліотеки |

## Структура

```
ciphers/common.py        алфавіт, підготовка тексту, перевірка ключів
ciphers/substitution.py  проста підстановка
ciphers/vigenere.py      шифр Віженера
ciphers/block.py         блокова перестановка
ciphers/columnar.py      вертикальна перестановка
cli.py                   консольний інтерфейс і робота з файлами
tests/                   автоматизовані тести pytest
```
