# Лабораторна робота 2. Квадрат Полібія та шифр Гронсфельда

Навчальна програма на Python, яка шифрує і розшифровує текст трьома режимами:

| Режим | Опис |
|---|---|
| `coordinates` | Координатний Полібій: символ → «рядок стовпець» (11…66), токени через один пробіл |
| `row-shift` | Циклічний зсув за рядками квадрата: символ → символ з наступного рядка (6 → 1) |
| `gronsfeld` | Шифр Гронсфельда: зсув літер на цифри ключа за модулем 33 (uk) або 26 (en) |

> ⚠ Класичні шифри не забезпечують конфіденційності й цілісності за сучасними вимогами.
> Не використовуйте їх для реальних паролів, токенів чи персональних даних.

## Вимоги

* Python **3.10+** (перевірено на Python 3.13)
* Для самої програми зовнішніх залежностей немає (лише стандартна бібліотека).
* Для тестів: `pytest`, `hypothesis` (див. `requirements.txt`).

```bash
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

```bash
python -m classic_ciphers --help
python -m classic_ciphers encrypt --help
```

Алфавіт (`--lang uk|en`), алгоритм (`--algo`) і ключ (`--key`) задаються **явно**; мова не вгадується.

```bash
# Координатний режим
python -m classic_ciphers encrypt --lang uk --algo coordinates --key БЕЗПЕКА --text "СЛАВА"
# 44 35 16 21 16
python -m classic_ciphers decrypt --lang uk --algo coordinates --key БЕЗПЕКА --text "44 35 16 21 16"
# СЛАВА

# Текст із пробілами: пробіли вилучаються окремою, видимою опцією
python -m classic_ciphers encrypt --lang uk --algo coordinates --key БЕЗПЕКА --text "Слава Україні" --strip-whitespace

# Циклічний зсув за рядками, з показом активного квадрата
python -m classic_ciphers encrypt --lang en --algo row-shift --key SECURITY --text "HELLO" --show-square
# OYVVZ

# Гронсфельд
python -m classic_ciphers encrypt --lang uk --algo gronsfeld --key 31415 --text "Слава Україні"
# ФМҐГД ЦЛФБНРЇ

# Робота з файлами UTF-8
python -m classic_ciphers encrypt --lang uk --algo gronsfeld --key 0271 --input examples/plain_uk.txt --output cipher.txt
python -m classic_ciphers decrypt --lang uk --algo gronsfeld --key 0271 --input cipher.txt --output restored.txt

# Показати ключовий квадрат
python -m classic_ciphers square --lang uk --key БЕЗПЕКА
```

Якщо не вказати ні `--text`, ні `--input`, текст вводиться вручну з клавіатури
(завершення: `Ctrl+D`, у Windows `Ctrl+Z` і `Enter`).

**Коди завершення:** `0` — успіх; `1` — некоректні дані (ключ, координати, файл);
`2` — некоректні аргументи командного рядка.

## Тести

```bash
python -m pytest -v
```

Результат: **147 тестів, усі проходять** (Python 3.13, pytest 8, hypothesis 6).

| Файл | Що перевіряє |
|---|---|
| `tests/test_vectors.py` | 6 контрольних векторів з розділу 7: шифрування і розшифрування |
| `tests/test_square.py` | 6×6, 36 унікальних символів, вилучення повторів ключа, NFC, некоректні ключові слова |
| `tests/test_polybius.py` | 11 і 66, перший/останній рядки, помилки 00, 17, 67 та ін., перехід 6 → 1, Ґ Є І Ї, A Z |
| `tests/test_gronsfeld.py` | ключ із початковим нулем, ключ 9, довгий, порожній, лише нулі; ключ не просувається на сторонніх символах |
| `tests/test_roundtrip.py` | D(E(x)) = x для 10+ повідомлень кожного режиму + генеративні тести Hypothesis (200 випадкових прикладів на режим) |
| `tests/test_cli.py` | CLI, `--help`, коди завершення, файли UTF-8 з кількома рядками та завершальним переносом, відсутність частково записаних файлів |

## Дані для звіту

```bash
python demo.py
```

Створює `results/report_data.md`: власні квадрати 6×6, таблицю контрольних векторів
(очікувано / фактично / статус) і власні приклади для всіх режимів.
Свої ключі й тексти можна задати в константах `OWN_*` у `demo.py`.

## Специфікація обробки тексту

| Аспект | Правило |
|---|---|
| Кодування | Файли читаються і записуються в UTF-8; програма працює з рядками Unicode |
| Нормалізація | Unicode NFC перед перевіркою ключа і тексту (`Ї` = `І` + U+0308 → U+0407) |
| Регістр | Лише підтримувані літери переводяться у верхній регістр; решта символів без змін |
| Алфавіти | uk: 33 літери `АБВГҐДЕЄЖЗИІЇЙКЛМНОПРСТУФХЦЧШЩЬЮЯ`, квадрат + `012`; en: 26 літер, квадрат + `0–9` |
| coordinates | Strict: лише символи квадрата; пробіли — помилка, якщо не задано `--strip-whitespace`. Токени: дві цифри 1–6 через **один** пробіл |
| row-shift | Символи квадрата зсуваються циклічно (вниз — шифрування, вгору — розшифрування); інші символи без змін. У латинському квадраті цифри теж зсуваються |
| gronsfeld | Змінюються лише літери вибраного алфавіту; пробіли, цифри, знаки й літери іншої мови не змінюються і **не споживають** цифру ключа |
| Ключ Гронсфельда | Рядок ASCII-цифр, не порожній, не лише нулі; початкові нулі зберігаються (`0271` ≠ `271`) |
| Ключове слово | Не порожнє, лише символи квадрата, щонайменше одна літера |
| Файли | Завершальний перенос рядка в координатному режимі вважається оформленням файлу. Результат пишеться через тимчасовий файл, тому при помилці частковий вихід не з'являється |

## Структура проєкту

```
classic_ciphers/
  alphabets.py   набори символів uk / en
  text.py        NFC, політика регістру, вилучення пробілів
  square.py      побудова квадрата 6x6 і таблиць пошуку (один раз)
  polybius.py    coordinates (суворий розбір токенів) і row-shift
  gronsfeld.py   перевірка ключа, шифрування/розшифрування
  service.py     перевірка режиму і виклик алгоритму
  cli.py         інтерфейс командного рядка, файли
  errors.py      CipherError з конкретними повідомленнями
tests/           автоматизовані тести
demo.py          генерація відтворюваних результатів для звіту
examples/        приклади вхідних файлів
```

Криптографічна логіка не залежить від інтерфейсу: CLI звертається лише до `service.process()`.
Таблиці пошуку будуються один раз, обробка тексту лінійна відносно його довжини.
